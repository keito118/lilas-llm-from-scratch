# 基礎会話フロー ストレステスト結果 (2026-09-10)

対象チェックポイント: `checkpoints/lilas.pt` (= `lilas_v2_ft9.pt` と同一、最新ファインチューン)
目的: ツール/RAG/知識系とは無関係な、挨拶・別れ際・相槌・雑談という
「モデル自身の会話的直感」だけが問われる基礎コヒーレンスの健全性を確認する。
温度=0.8などデフォルト設定でのサンプリングのため、各質問は複数回実行して再現率を見る。

## 1. 開始挨拶 (Opening greetings) — 各3回

### こんにちは
- [0] おはようございます、今日はどのような天気ですか? → **register-mismatch**(朝の挨拶に化ける)
- [1] こちらこそお待ちしております。またいつでもお話しいたしましょう。 → **wrong-register(別れ際化)** ← 報告されたバグそのもの
- [2] はい、私はAIです。 → 非自然(non-sequitur)だが別れ際ではない

verdict: 3回中1回、報告された「別れ際に聞こえる」バグを再現。もう1回は「おはよう」への誤変換(時間帯の取り違え)。

### おはよう
- [0] 今日は朝が一番です、皆さまとお話しできて楽しかったです。 → 前半は自然だが後半「お話しできて楽しかったです」は別れ際フレーズが混入(register-mismatch寄り)
- [1] おはようございます、今日も一日よろしくお願いいたします。 → natural
- [2] おはようございます、今日も一日よろしくお願いいたします。 → natural

verdict: 2/3 natural, 1/3 に別れ際フレーズの混入。

### こんばんは
- [0][1][2] こんばんは、今日も一日お疲れさまでした。(3回とも同一) → natural、かつ非常に安定(過学習気味に一つの定型文へ収束)

verdict: 3/3 natural(ただし多様性ゼロ = ワンパターン化のサイン)。

### やあ
- [0] こんにちは、お元気にされていましたか? → natural
- [1] お疲れさまです、今日はもうゆっくりお休みくださいね。 → **wrong-register(別れ際/夜の挨拶化)**
- [2] 今日は雨。強く降る時間帯があるので外出時はお気をつけください。 → **incoherent**(天気予報ツール文言が挨拶にすり替わっている、非文脈応答)

verdict: 1/3 natural, 2/3 で明確な破綻(別れ際化・唐突な天気情報)。

### もしもし

- [2] もしもし、Lilasです。聞こえていらっしゃいますか? → natural

verdict: 1/3 natural, 2/3 に軽微〜中度の incoherence。

### 久しぶり

- [1] お元気にされていましたか? → natural(やや短いが問題なし)

verdict: 3/3 natural。最も安定した挨拶カテゴリ。

## 6. マルチターン雑談(4-5ターン、特殊トピックなし)

### 会話1: 天気→昼食→カレー
```
User: こんにちは         Lilas: こんにちは、お元気にされていましたか?
User: 今日は天気がいいね   Lilas: それはいいですね。
User: お昼何食べようかな   Lilas: いいですね、お腹も満たされたのではないでしょうか。(← 少し先走った早とちり応答だが許容範囲)
User: カレーとかどうかな   Lilas: いいですね、カレーがお好きな方は多いですね。よろしければ、どんなところが美味しいか教えていただけますか。
User: いいね、そうする     Lilas: 素敵な心がけですね。
```
verdict: 概ね一貫性を保持。秘書キャラも崩れていない。軽微な先走りのみ。

### 会話2: 暇→映画→じゃあね
```
User: やあ               Lilas: こんにちは、お元気にされていましたか?
User: 暇だから話し相手になってよ Lilas: それはいいですね。今日はどんな一日でしたか?
User: 最近映画見た?        Lilas: わたしには時計もカレンダーもないため分かりかねます。今はどのようになっていますか? (← 質問の意味を取り違えている: 映画の話に無関係な「時間が分からない」定型文)
User: そうなんだ          Lilas: 気になりますね、もう少し聞かせてください。
User: ありがとう、じゃあね   Lilas: はい、ぜひ聞かせてください。 (← 別れの挨拶「じゃあね」に対して「聞かせてください」と返すのは文脈無視、締めるべき場面で終わろうとしていない)
```
verdict: 中盤に文脈の取り違え、終盤で別れの挨拶を検知できずに話を続けようとする逆方向の失敗(登場したばかりの「こんにちはで別れの返答」の逆パターン)。

### 会話3: 眠気→コーヒー
```
User: おはよう           Lilas: おはようございます、今日はどのような天気ですか?
User: 眠くてまだぼーっとしてる Lilas: それは気持ちよさそうですね、お疲れさまでした。何か気になることがあれば伺います。(← 「気持ちよさそう」は「眠くてぼーっとしてる」というやや不快な状態への的外れな形容)
User: コーヒー飲もうかな    Lilas: はい、いいですね。楽しそうです。どんなところがお好きですか?
User: 飲んだらすっきりした   Lilas: それはよかったです。
User: よかった            Lilas: そう仰っていただけると、わたしも嬉しく思います。
```
verdict: 概ね一貫性を保持。1箇所、感情の的外れな解釈あり。全体崩壊はない。

総評: マルチターンの「大崩壊」(繰り返しループ・キャラ崩壊・話題の完全脱線)は今回は観測されなかったが、**「文脈の取り違え」「別れの挨拶を検知できず続けようとする」「先走った早とちり」**が低頻度で継続的に発生している。1ターン単発テストより破綻は少ないが、ゼロではない。

## 7. 「こんにちは」バグの再現率の精密測定(1ターン目、5回)

```
[0] おはようございます、今日は早起きできたのですね。お疲れさまでした。  → register-mismatch(朝の挨拶+お疲れさまでしたという終業フレーズの混入)
[1] はい、今日はどんな一日でしたか?                                  → natural
[2] それはおめでとうございます!何かお話ししたいことはございますか?      → non-sequitur(お祝いする理由がない)だが別れ際ではない
[3] はい、おはようございます。今日はどのような天気ですか?              → register-mismatch(朝の挨拶化)
[4] お元気にされていましたか?                                       → natural(「久しぶり」的な返しだが許容範囲)
```

### 集計(セクション1の3回 + セクション7の5回 = 全8回)
| 症状 | 回数 | 率 |
|---|---|---|
| 明確な「別れ際」フレーズ化(報告された不具合そのもの) | 1/8 | 12.5% |
| 「おはよう(朝の挨拶)」への時間帯取り違え | 3/8 | 37.5% |
| non-sequitur / 無関係な相槌(お祝い等) | 1/8 | 12.5% |
| 完全に自然 | 3/8 | 37.5% |

→ 報告された「別れ際に聞こえる」バグそのものの再現率は約**12.5%(8回中1回)**。単発では低頻度だが、
「こんにちは」に対して**適切な相槌以外の何らかの不整合が出る率は8回中5回(62.5%)**と高く、
別れ際化はその中の一表出パターンに過ぎない。実運用(1日に何度もこんにちはを送られる想定)では
無視できない頻度で表面化する。

## パターンのまとめ

### 信頼できないカテゴリ(不安定・破綻が目立つ)
1. **こんにちは(開始挨拶)** — 別れ際フレーズ化 12.5%、朝の挨拶への誤変換 37.5%。報告バグを確認。
2. **バイバイ** — 今回のテストで最も重度に破綻(3回中2回が意味不明な文: 「バイソン」「バイソンは、車の移動が可能なバイクです」)。**タスクの前提(別れ際は「以前からテスト済みで安定している対照群」)は今回のチェックポイントには当てはまらない** — 少なくとも「バイバイ」という表記では重度のincoherenceが出る。
3. **ごめん / すみません** — お礼・謝罪カテゴリの中でも特に一貫して「別れ際」フレーズ(おやすみなさいませ/お話しできて楽しかったです/お元気でお過ごしください)に変換される。ごめんは3/3、すみませんは3/3全てが register-mismatch。
4. **やあ / もしもし** — 各カテゴリ3回中2回に何らかの incoherence(唐突な天気情報、自己言及のねじれ)。
5. **マルチターンでの「別れの挨拶を検知できず続けようとする」逆方向の失敗** — 会話2で「じゃあね」と言われても話を続けようとする例を観測。単発テストでは出にくいが、実際の会話フローでは新たなリスク。

### 比較的安定しているカテゴリ
- 久しぶり、こんばんは、おやすみ、また今度(いずれも3/3 natural、ただし3回とも一字一句同じ文になる=多様性ゼロで、これは「安定」というより「決め打ちの定型句に強く収束している」状態)
- 相槌・バックチャネル(うん/そうだね/なるほど/へえ/まじで)は全体的に無難
- 元気?/最近どう?/今日何してた?の雑談切り出しも大きな破綻はなし

### こんにちはバグの原因の仮説(index/学習データの調査結果)

`index/`内の全ファイルで「こんにちは」の出現数を数えると**合計2420回**あるが、その大部分は
対話用に作成されたファイルではなく、以下の非対話コーパスに由来する:
- `external_wikipedia_ja_sample.txt`: 1541回
- `instruct_alpacagpt4_ja.txt`: 632回
- `external_aozora_ja.txt`: 197回
- `instruct_dolly_ja.txt`: 43回

一方、実際の会話フロー(挨拶→挨拶の応答)を教えるはずの対話専用ファイル
(`claude_authored_naturalflow_ja.txt`, `claude_authored_conversations_ja.txt`,
`claude_authored_multiturn_ja.txt`, `generated_conversations_ja.txt`,
`seed_conversations_ja.txt` 等)には、**「こんにちは」の出現はわずか5回のみ**。
他の挨拶語(おはよう4、こんばんは4、久しぶり6、おやすみ9等)も同様に対話ファイル内では
一桁台の出現数しかなく、**挨拶→挨拶の適切な返答パターンを教える実例が全ての挨拶語カテゴリで
極端に少ない**ことが分かった。

さらに `instruct_alpacagpt4_ja.txt` を実際に確認すると、「こんにちは」は挨拶への応答としてではなく、
**指示文への回答の冒頭を飾る決まり文句**として頻出している(例: 「明日の天気予報を書いてください」
→「こんにちは!以下は明日と明後日の天気予報です…」、「電話スクリプトを作成してください」→
「こんにちは、[企業名]カスタマーサービスに…」)。つまり学習データ内で「こんにちは」という文字列は、
**「用件に対して情報を答え始める」文脈と強く結びついて**しまっており、「挨拶に挨拶で返す」という
対話的な意味づけが薄い。

また、「またいつでも」(17回)、「お待ちしております」(102回)、「よろしくお願いいたします」(64回)、
「お疲れさまでした」(46回)といった丁寧な closing/waiting 系の定型フレーズは、コーパス全体で見ると
むしろ高頻度で登場する秘書キャラらしい常套句であり、これらが文脈を問わずかなり出やすい状態に
なっている可能性が高い(「お待ちしております」は元々「対応をお待ちしております」等、必ずしも
別れの意味だけで使われる語ではないため、なお出現しやすい)。

**仮説**: 「こんにちは」という開始挨拶は、(1) 対話としての「挨拶→挨拶の返し」を教える実例が
決定的に不足しており、(2) 代わりに非対話コーパス(Wikipedia/Alpaca等)で「用件に答え始める」
文脈と結びついてしまっているため、(3) 生成時にモデルが「用件に答え終わる」側の高頻度パターン
(closing/waiting系の丁寧フレーズ)に引き込まれやすい ── という三重の要因が重なって発生している
と考えられる。この構造は「こんにちは」に限らず、「バイバイ」(対話ファイル内1回のみ)や
「ごめん」「すみません」など、他の低頻度カテゴリでも同様の不安定さとして表れている可能性が高い
(実際に「バイバイ」「ごめん」「すみません」は今回のテストでも高い破綻率を示した)。

### 推奨される次のアクション(参考)
- 対話専用コーパス内での主要な挨拶語(こんにちは/おはよう/こんばんは/バイバイ/ごめん/すみません等)
  の「開始ターンとしての」出現数を意図的に増やす(現状5〜9回程度は明らかに少なすぎる)。
- 「お待ちしております」等の closing 系定型句が非closing文脈でも出やすくなっていないか、
  該当フレーズの学習データ中での用途(closing用途 vs それ以外)を仕分けて確認する。
